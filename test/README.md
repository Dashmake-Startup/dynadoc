

Extensions:
.xddoc : Open XHTML dynamic document file (default & free)
.sddoc : Secured XHTML encrypted dynamic document file (encrypted & paid subscription)

To manually zip  and unzip .xddoc files
zip -r my-document.xddoc my-folder/

cd /path/to/Documents/ && zip -r test.xddoc test

cd test/ && zip -r test.zip test/

cd test/ && zip -r test.xddoc test/

or if in test/ dir

zip -r test.xddoc test/


unzip my-document.xddoc -d extracted-folder/
